# AI Infographic Generator

Generate full-page illustrated infographics as PDF / PNG / SVG from a single
topic prompt. Content is written by an LLM (Ollama), a full-page portrait
illustration is generated by SDXL (ComfyUI), and the two are composited into a
clean A4 "poster" you can review, edit, and re-render.

The web UI lives at `http://localhost:8090` (configurable). Generate a topic,
review and edit the AI-written content, render the illustration, and download
the finished infographic.

## Features

- **Content generation with Ollama** — topic, audience, visual style, and
  section count are turned into structured, schema-validated content with a
  corrective retry loop (`OLLAMA_MAX_ATTEMPTS`).
- **Illustration rendering with ComfyUI / SDXL** — one full-page portrait
  image (1024×1448) that becomes the background of the poster. The checkpoint
  is configured via `COMFYUI_CHECKPOINT`, and the per-section
  `visual_description` fields are woven into the page prompt as visual motifs.
- **Poster compositing** — the text is laid out *into* the artwork with no card
  boxes: a light scrim unifies the art, a left dark gradient keeps the text
  legible, and four accent themes cycle per section.
- **Editable review page** — every content field binds to the schema; edits
  POST to `/save-content` and are never lost on validation failure.
- **Project library & activity feed** — thumbnail grid of every project
  (draft vs rendered), search by topic/audience/style, pagination, hard
  delete, and a history of generation tasks.
- **Resilient async tasks** — a JSONL journal survives restarts, tasks are
  serialized per kind with a bounded queue, interrupted tasks get a clear
  "restart" message instead of spinning forever, and failed tasks offer a
  one-click **Try again** that re-runs the exact stored form.
- **Project janitor** — automatic cleanup of projects older than a configurable
  retention window (default 30 days).

## Requirements

- Linux host with an **NVIDIA GPU** (ComfyUI renders SDXL; the compose service
  requests a GPU device).
- **Docker** with Compose v2 and the **NVIDIA Container Toolkit** installed
  (see `docs/DEPLOYMENT.md`).
- A running **Ollama** server with the configured model pulled
  (`OLLAMA_MODEL`, default `gemma4:12b`).
- The **SDXL base checkpoint** placed in `comfyui/models/checkpoints/`
  (`COMFYUI_CHECKPOINT`, default `sd_xl_base_1.0.safetensors`).
- Disk space: the `comfyui/` install is roughly 6.6 GB on top of the model
  files; rendered `output/` accumulates until the janitor cleans it up.

## Quick start

```bash
# 1. Configure (copy the template into a git-ignored .env)
cat > .env <<'EOF'
OLLAMA_URL=http://host.docker.internal:11434
OLLAMA_MODEL=gemma4:12b
COMFYUI_URL=http://comfyui:8188
COMFYUI_CHECKPOINT=sd_xl_base_1.0.safetensors
APP_PORT=8090
EOF

# 2. Make sure the model + checkpoint are available
ollama pull gemma4:12b
# ...and sd_xl_base_1.0.safetensors is in comfyui/models/checkpoints/

# 3. Start everything
docker compose up --build -d
```

Open http://localhost:8090, enter a topic, and follow the flow:

1. **Generate Content** — Ollama writes the content (this can take a minute or two).
2. **Review & edit** — tweak titles, descriptions, and bullets, then
   **Generate infographic** (re-check **Regenerate the page illustration** to
   force a new SDXL image).
3. **Result** — download the **PDF / PNG / SVG** or regenerate the illustration.
4. **Library** and **Activity** — revisit and manage everything generated on
   this server.

See `docs/DEPLOYMENT.md` for full first-run setup and `docs/TROUBLESHOOTING.md`
for common problems.

## Configuration

All options are environment variables read by the *compose file*; the app also
has matching defaults in `app/config.py`. The app itself does not load `.env`
(it relies on the process environment) — put real values in `.env` at the repo
root, which Compose reads.

| Variable | Default | Description |
| --- | --- | --- |
| `APP_PORT` | `8090` | Host port mapped to the app container's internal `8080`. |
| `OLLAMA_URL` | `http://host.docker.internal:11434` | Base URL of the Ollama server. |
| `OLLAMA_MODEL` | `gemma4:12b` | Model used for content generation. |
| `OLLAMA_MAX_ATTEMPTS` | `3` | Corrective retries for invalid JSON / schema mismatches. |
| `COMFYUI_URL` | `http://comfyui:8188` | Base URL of the ComfyUI server. |
| `COMFYUI_CHECKPOINT` | `sd_xl_base_1.0.safetensors` | Checkpoint name applied to the ComfyUI workflow's checkpoint loader at render time. |
| `COMFYUI_MAX_WAIT_SECONDS` | `1200` | Cap on how long to wait for a ComfyUI workflow. |
| `TASK_TTL_SECONDS` | `1800` | How long finished tasks stay in memory before pruning. |
| `MAX_QUEUED_PER_KIND` | `2` | Max queued tasks per kind (one running + this many queued). |
| `TASKS_DIR` | `/app/tasks` | Where the JSONL task journal lives. |
| `PROJECT_RETENTION_SECONDS` | `2592000` | Delete projects older than this (0 disables the janitor). |
| `CLEANUP_INTERVAL_SECONDS` | `3600` | How often the janitor sweep runs. |

Runtime data lives in git-ignored `output/`, `projects/`, and `tasks/`
directories (bind-mounted into the container). If any of these are missing or
not writable at boot, the app **fails fast** on purpose.

## Project structure

```
app/
  main.py            # FastAPI app factory, lifespan, static mount
  config.py          # settings from environment
  models.py          # InfographicContent / Section Pydantic schemas
  services.py        # ContentService, RenderingService
  workers.py         # content_worker, infographic_worker
  tasks.py           # TaskManager (queue, lifecycle, journal)
  task_store.py      # JSONL journal persistence
  storage.py         # ProjectRepository, OutputStore
  cleanup.py         # ProjectJanitor (retention sweep)
  renderer.py        # SVG builder + cairosvg PNG/PDF output
  ollama_client.py   # LLM content with corrective retries
  comfyui_client.py  # SDXL image generation via ComfyUI API
  routes_ui.py       # index/review/result/save/generate/file routes
  routes_tasks.py    # task status + error pages
  routes_library.py  # library, thumbnail, delete, activity
  templates/         # Jinja2 pages
  static/            # CSS + page JS
  workflows/         # ComfyUI API workflow (illustration_api.json)
comfyui/             # git-ignored ComfyUI install + models (host mount)
output/              # git-ignored rendered files (infographic.{svg,png,pdf})
projects/            # git-ignored project content (project.json per project)
tasks/               # git-ignored task journal (journal.jsonl)
tests/               # pytest suite
scripts/verify.sh    # test + lint + smoke gate
smoke_test.py        # dependency-light smoke test
```
